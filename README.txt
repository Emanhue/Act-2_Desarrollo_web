# Hoja de vida web — Unidad 2

Proyecto académico de Desarrollo Web. A partir de la hoja de vida de la Unidad 1 se incorporó Bootstrap para mejorar el diseño y la adaptación a dispositivos móviles.

## Implementaciones de la Unidad 2
- Bootstrap 5.3.3 mediante CDN para componentes, grid, botones, navegación, tarjetas, tabla y formulario responsive.
- jQuery 3.7.1 para animaciones de entrada, efectos de aparición y dinamismo visual.
- JavaScript para validar nombre, correo electrónico, motivo y mensaje.
- Mensajes visuales de validación y confirmación.
- Menú responsive con botón hamburguesa.
- Diseño conservando la información personal y académica de la Unidad 1.

## Archivos
- index.html: presentación principal.
- perfil.html: información personal y académica.
- formacion.html: trayectoria y áreas de conocimiento.
- proyectos.html: portafolio.
- contacto.html: formulario validado.
- styles.css: estilos personalizados.
- script.js: jQuery y validación JavaScript.
- assets/perfil.svg: recurso gráfico.

## Cómo ejecutar
Abre `index.html` en un navegador con conexión a Internet para cargar Bootstrap y jQuery desde sus CDN.
